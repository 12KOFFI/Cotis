 5. SQL À EXÉCUTER EN PRODUCTION (phpMyAdmin)

⚠️  Ce ne sont PAS des nouvelles colonnes.
    Ce sont des INDEX de performance sur des colonnes EXISTANTES.
    Aucune donnée n'est modifiée, aucun risque de perte.
    Cela accélère les requêtes du dashboard et des calculs de solde.

--- Copier/coller ce bloc dans phpMyAdmin → Onglet SQL → Exécuter ---

-- Index sur la table caisse_ledgers (accélère les calculs de solde caisse)
ALTER TABLE `caisse_ledgers` ADD INDEX `idx_ledger_caisse` (`caisse_id`);
ALTER TABLE `caisse_ledgers` ADD INDEX `idx_ledger_groupe_type` (`groupe_id`, `type`);

-- Index sur la table paiements (accélère le dashboard et les statuts membres)
ALTER TABLE `paiements` ADD INDEX `idx_paiements_cotisation_lookup` (`membre_id`, `periode_id`, `type`, `statut`);
ALTER TABLE `paiements` ADD INDEX `idx_paiements_statut` (`statut`);
